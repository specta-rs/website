# Specta website

Website for documenting Specta projects. Built using [Waku](https://waku.gg), [Fumadocs](https://www.fumadocs.dev) and [TailwindCSS](https://tailwindcss.com).

## Usage

```bash
pnpm i
pnpm dev
```

## Sponsors
