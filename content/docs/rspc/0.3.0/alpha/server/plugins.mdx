---
title: Plugins
description: Extension status for the archived alpha documentation.
---

The plugin ideas in these alpha notes did not become a finished plugin API in rspc 0.3.0. There is no supported installation flow for the planned OpenAPI, playground, or authentication plugins.

For an existing 0.3.0 application, use [router middleware](/docs/rspc/0.3.0/server/middleware) and ordinary web-framework routes. See [0.3.0 extension options](/docs/rspc/0.3.0/server/plugins).

The experimental rewrite's extension crates use a different API and several remain incomplete. They are not compatible replacements for a 0.3.0 plugin.
